# 環境構築

## 1. 目的

学習支援Webアプリの設計、UIモック、実装を安全かつ再現可能な環境で進めるため、開発環境の構築手順を管理する。

環境構築は、ツールを導入するだけでなく、次の状態を満たすことを完了条件とする。

- 別の開発者または別の端末でも、同じ手順で環境を再現できる
- 認証情報や秘密情報をリポジトリへ保存しない
- 各ツールの導入目的と確認方法が分かる
- 問題が発生した場合に、原因を切り分けられる

## 4. 共通ルール

- パスワード、APIキー、秘密鍵、アクセストークンはGitで管理しない。
- 環境固有の設定値は、将来作成する`.env.example`などのサンプルファイルで項目だけ共有する。
- コマンドを実行した後は、各ドキュメントに記載した確認コマンドで結果を検証する。
- 導入したツールのバージョンは、基本設計で技術スタックを確定した後に固定する。
- 手順を変更した場合は、実際に再実行できる内容になっているか確認する。

## 5. ドキュメント更新方針

環境構築手順は、次の場合に更新する。

- 採用する技術スタックまたはバージョンを変更した場合
- 新しい開発端末で手順を再現できなかった場合
- セキュリティ上の推奨手順が変わった場合
- 開発に必要な外部サービスを追加した場合
