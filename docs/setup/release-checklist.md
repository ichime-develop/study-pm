## 3. 必須チェック

### 3.1 セキュリティ

以下は[非機能要件](../requirements/details/non-functional.md)のNFR-SEC-01〜06と、[実装方針](../detailed-design/implementation-policy.md)のCookie/CORS・設定管理方針に対応する。

- [ ] HTTPSを強制し、HTTPからHTTPSへのリダイレクトを確認した。
- [ ] HSTS、`X-Content-Type-Options: nosniff`、`Referrer-Policy`、クリックジャッキング対策のヘッダーを、アプリまたはリバースプロキシで設定・確認した。
- [ ] 本番用の`JWT_SECRET`を秘密情報管理または環境変数から注入した。開発用の値、リポジトリ上の値、ログ出力を使用していない。
- [ ] `REFRESH_COOKIE_SECURE=true`を設定し、本番プロファイルで`false`の場合は起動しない検証を確認した。
- [ ] refresh token Cookieの`HttpOnly`、`Secure`、`SameSite`、`Path`が[API一覧](../basic-design/api-list.md)の認証仕様と一致することを実際のHTTPレスポンスで確認した。
- [ ] `FRONTEND_ORIGIN`を本番ドメインへ設定し、CORS許可originにワイルドカードを使用していない。credentials利用時の許可originが明示されている。
- [ ] OpenAPIとSwagger UIを本番で無効化するか、認証を必須にした。
- [ ] ログイン、登録、refreshエンドポイントにレート制限を設定し、設定値と超過時の応答を確認した。
- [ ] 認証失敗は、メールアドレスとパスワードのどちらが誤っているか特定できない応答であることを確認した。
- [ ] 他ユーザーのプロジェクト、WBSタスク、学習記録に対する取得・更新・削除が404になることを結合テストまたはステージング環境で確認した。
- [ ] パスワード、JWT、refresh token、Cookie値、`Authorization`ヘッダーをアプリケーションログに出力しないことを確認した。
- [ ] ログイン成功・失敗、ログアウト、想定外例外が、秘密情報を含めずにログへ記録されることを確認した。
- [ ] `npm audit`とMaven依存関係の脆弱性確認を実施し、未解決の項目は影響評価と受容理由を記録した。

### 3.2 秘密情報と環境設定

- [ ] DB接続情報、JWT秘密鍵、外部サービスの認証情報をリポジトリへ含めていない。
- [ ] 本番DBのアカウント、パスワード、接続先を開発用の既定値から変更した。
- [ ] 本番設定でアプリケーションを起動し、必須環境変数の不足時に安全に起動失敗することを確認した。
- [ ] 本番環境のエラー応答にスタックトレース、SQL、内部クラス名、秘密情報が含まれないことを確認した。

### 3.3 品質と動作確認

- [ ] backendの単体テスト・結合テスト、frontendのlint・typecheck・テスト・buildが成功した。
- [ ] 新規登録、ログイン、ログアウト、プロジェクト作成、WBS編集、学習記録CRUD、概要集計の主要導線をステージングまたは本番相当環境で確認した。
- [ ] 公開対象ブラウザである最新Google Chromeで主要画面を確認した。
- [ ] リリース対象のDBマイグレーションを、バックアップ済みの環境で実行・検証した。

### 3.4 運用と復旧

- [ ] DBバックアップを実行し、保持期間と復元手順を確認した。
- [ ] 直近バックアップからの復元を検証した、または復元演習の記録を確認した。
- [ ] 監視対象、障害通知先、ログの保存先と保持期間を決めた。
- [ ] ロールバック対象のアプリケーションバージョン、DB変更の戻し方、判断者を記録した。

## 4. 条件付きチェック

該当する機能または構成を採用する場合だけ確認する。

- [ ] frontendとAPIを別サイトへ配置する場合、Cookie属性とCORS方針を再設計・検証した。
- [ ] AI機能を公開する場合、送信データがNFR-SEC-07、NFR-SEC-08で許可した範囲に限定されていることを確認した。
- [ ] パスワード再設定を提供する場合、再設定トークンの有効期限、使い捨て、レート制限、監査ログを確認した。
- [ ] メールアドレスの登録済み判定を公開上のリスクとして扱う場合、メール確認フローまたは同一応答化の方針を決定・記録した。
