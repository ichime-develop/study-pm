# PC Web版 最終MVP UIモック画面計画

## 1. 対象範囲

PC Web版の最終MVP主要画面を先にモック化し、UIとページ遷移を確認する。

Flutterスマホアプリは別リポジトリ `study-pm-mobile` で作成する想定とし、このリポジトリではPC Web版の画面確認に集中する。

将来のFlutterスマホアプリからも利用できるよう、業務ルール、データ、APIは共通化を前提にする。

画面イメージを確認したうえで、MVPを段階リリースするか、一括リリースに近づけるかを再検討する。

対象機能:

- 認証
- 学習プロジェクト管理
- WBS管理
- 学習記録管理
- 進捗可視化
- 質問管理
- AI回答
- AI学習計画生成
- ダッシュボード

## 4. ダミーデータ方針

ダミーデータは、要件確認に必要な状態を含める。

- 進行中プロジェクト
- 未着手プロジェクト
- 完了プロジェクト
- アーカイブ対象の例
- 親タスクとリーフタスクを含むWBS
- 遅延しているリーフタスク
- 今日から今後7日以内の予定タスク
- 完了済みリーフタスク
- 直近の学習記録
- 未解決、調査中、解決済みの質問
- 回答メモ
- AI回答履歴
- AI送信情報として選択できる学習記録と回答メモ
- チャット型入力欄で目次テキスト、写真、画像ファイルをまとめて送信する例
- AIが生成したWBS、予定日、予定工数の確認例

## 5. 確認観点

### 5.1 ダッシュボード

- 進行中プロジェクトの状況がすぐ分かるか
- 今日から今後7日以内の予定タスクが見つけやすいか
- 遅延タスクが視覚的に区別されているか
- 学習記録を追加する導線が分かるか

### 5.2 プロジェクト一覧

- アーカイブ済みを通常一覧から除外する前提が自然か
- 状態、進捗率、工数、期間が比較しやすいか
- プロジェクト詳細へ進む導線が分かるか

### 5.3 プロジェクト詳細

- 親タスクの自動集計値とリーフタスクの入力値の違いが分かるか
- 学習記録とWBS編集への導線が分かるか
- 進捗率、予定工数、実績工数の関係が理解しやすいか

### 5.4 WBS編集

- 5階層まで扱える画面として破綻しないか
- インデント・アウトデントの操作が理解できるか
- 学習記録があるリーフタスクを親化できない制約を説明できるか

### 5.5 学習記録登録

- リーフタスクだけを選択できることが伝わるか
- 0.25時間単位の入力が自然か
- 完了済みリーフタスクにも追加記録できることが分かるか

### 5.6 進捗可視化

- EVM指標とWBSが同じプロジェクト詳細に置かれていて理解しやすいか
- バーンダウンチャートをどの大きさで表示すべきか
- 計画不整合、遅延、工数超過を区別できるか

### 5.7 質問管理

- 質問状態の違いが分かるか
- 回答メモがないと解決済みにできない制約が伝わるか
- 関連プロジェクトと関連タスクの関係が自然か

### 5.8 AI回答

- AI回答と回答メモの違いが分かるか
- 外部送信の初回同意と送信情報選択が重くなりすぎないか
- 過去のAI回答履歴と再生成導線が分かるか

### 5.9 AI学習計画生成

- ChatGPTやGeminiのようなシンプルな入力欄で、教材目次入力が自然にできるか
- `+` メニューから写真アップロード、画像ファイルアップロード、テキスト貼り付けの導線を選べるか
- 複数画像を添付した場合に、添付数、上限、並び順が分かるか
- 画像は最大10枚、1画像10MB以内、合計50MB以内であることを自然に伝えられるか
- 入力欄右下の実行ボタンと停止ボタンが分かりやすいか
- OCR後の目次テキストを入力欄内で修正してから生成できる導線になっているか
- 学習目的、期限、学習可能時間、制約をフォームではなく自然文で依頼できるか
- 作成後に「この日は勉強できなくなった」などの追加依頼でスケジュール修正案を作れるか
- AI修正案を直接反映せず、変更差分を確認して承認する流れが分かるか
- AI生成結果を直接保存せず、ユーザー確認後にプロジェクトとWBSを作成する前提が自然か
- 生成結果の履歴を残す必要があるか、保存後のプロジェクト・WBSだけで十分か

## 6. 将来のスマホアプリ版との関係

Flutterスマホアプリ版は、別リポジトリ `study-pm-mobile` で作成する。

将来的にはPC Web版と同じ主要機能を提供する。

ただし、UIは次のように最適化する。

| 機能 | PC Web版 | Flutterスマホアプリ版 |
| --- | --- | --- |
| WBS編集 | 表形式、横並び情報、ドラッグやボタン操作 | カード形式、段階操作、詳細編集 |
| EVM確認 | グラフと指標を同時表示 | 要約表示から詳細へドリルダウン |
| AI計画作成 | チャット型入力欄、`+` メニュー、写真・画像ファイル添付、実行・停止ボタン | カメラ撮影、画像選択、OCR結果の分割確認 |
| 学習記録 | 一覧とフォームを併用 | 今日のタスクから少ない操作で登録 |
| 質問管理 | 一覧、詳細、AI履歴を広く表示 | 質問作成と状態更新をカードで操作 |
