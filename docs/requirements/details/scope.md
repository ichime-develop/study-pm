# 基本方針・スコープ・ユースケース

## 6. 基本方針

### 6.1 最終MVPの考え方

最終MVPでは、学習計画を手動またはAI支援で登録し、日々の学習実績を入力して、進捗を可視化する基本サイクルを完成させる。

```text
学習プロジェクト作成
  -> 教材目次からAI学習計画案を生成
  -> WBS作成
  -> 学習予定の設定
  -> 学習記録の登録
  -> 進捗率の更新
  -> ダッシュボードで状況確認
  -> 質問と回答メモの蓄積
  -> 必要に応じてAI回答を参考にする
```

### 6.2 最終MVPでの前提

- PC Webから利用する。
- 将来のFlutterスマホアプリからも同じアカウント、同一バックエンドAPI、同一データを利用できる構成を前提にする。
- ユーザーはメールアドレスとパスワードでログインする。
- 1つのWBSタスクは1つの学習プロジェクトに所属する。
- WBSは最大5階層で管理できる。
- 工数の単位は「時間」とし、0.25時間単位で入力できる。
- リーフタスクの進捗率はユーザーが手動で更新する。
- 実績工数は学習記録から自動集計する。
- 登録した質問に対するAI回答を生成し、回答メモと区別して保存できる。
- 教材目次画像または修正済み目次テキストから、AI学習計画案を生成できる。

### 6.3 段階リリース

最終MVPの機能範囲は維持し、開発と受入確認を次の単位に分割する。

| リリース | 目的 | 対象機能 |
| --- | --- | --- |
| MVP 1 | 学習計画と実績を管理できる | 認証、プロジェクト、WBS、学習記録、基本ダッシュボード |
| MVP 2 | 計画との差を可視化できる | 進捗履歴、計画履歴、EVM、バーンダウン、遅延表示 |
| MVP 3 | 学習中の疑問を蓄積できる | 質問管理、回答メモ |
| MVP 4 | AIを学習支援へ利用できる | AI回答生成、再生成、回答履歴、教材目次OCR、AI学習計画生成 |

## 7. スコープ

### 7.1 最終MVPの対象範囲

| 区分 | 対象機能 |
| --- | --- |
| ユーザー管理 | アカウント登録、ログイン、ログアウト |
| 学習プロジェクト管理 | 作成、編集、一覧、詳細、完了、アーカイブ、復元 |
| WBS管理 | 階層タスクの作成、編集、上下移動、階層変更、進捗更新 |
| 学習記録管理 | 学習時間、学習日、対象タスク、メモの登録・編集・削除 |
| 進捗可視化 | 予定工数、実績工数、進捗率、EVM、バーンダウンチャート |
| 質問管理 | 質問、状態、回答メモ、関連タスクの登録・検索 |
| AI回答 | AI回答生成、再生成、回答履歴 |
| AI学習計画生成 | 教材目次画像のOCR、OCR結果修正、生成条件入力、WBS・学習計画案生成、保存前確認 |
| ダッシュボード | プロジェクトの進捗、遅延、予定タスク、学習記録、未解決質問の確認 |

### 7.2 最終MVPの対象外

- Googleログイン
- Googleカレンダー同期
- パスワード再設定
- メールアドレス確認
- アカウント削除
- プロジェクトの物理削除
- AI学習計画生成でのPDF、Officeファイル、URL読み込み
- チーム、講師、共有、コメント機能
- 通知、リマインダー機能
- 課金機能
- 外部公開用プロフィール

### 7.3 将来拡張

| 優先度 | 機能 | 概要 |
| --- | --- | --- |
| 中 | Googleログイン | Googleアカウントで認証する |
| 中 | Googleカレンダー同期 | 学習予定をカレンダーに登録・更新する |
| 中 | 学習状況共有 | メンター、リーダー、後輩との1on1で学習計画、進捗、質問を共有できるようにする |
| 低 | 学習通知 | 予定開始前、遅延時、未解決質問の通知を行う |
| 低 | 学習レポート | 週次・月次の学習実績を集計する |

## 8. 主要ユースケース

| ID | ユースケース | 概要 |
| --- | --- | --- |
| UC-01 | 学習計画を作成する | ユーザーは学習プロジェクトを作成し、学習内容をリーフタスクまで分解する |
| UC-02 | 学習実績を記録する | ユーザーは実施した学習時間とメモをリーフタスクへ登録する |
| UC-03 | 進捗を更新する | ユーザーはリーフタスクの進捗率を更新し、親タスクとプロジェクトの集計値を確認する |
| UC-04 | 計画との差を確認する | ユーザーは遅延タスク、EVM、バーンダウンを確認する |
| UC-05 | 疑問を管理する | ユーザーは質問、回答メモ、状態を登録し、後から検索する |
| UC-06 | AI回答を参考にする | ユーザーは外部送信に同意し、選択した学習情報を含めてAI回答を生成する |
| UC-07 | 学習プロジェクトを完了・整理する | ユーザーは全タスク完了後にプロジェクトを完了し、必要に応じてアーカイブ・復元する |
| UC-08 | AIで学習計画案を作成する | ユーザーは教材目次画像または目次テキストからOCR結果を修正し、AIが生成したWBSと予定を確認して保存する |
