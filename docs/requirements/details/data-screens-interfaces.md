# データ・画面・外部インターフェース

## 15. データ要件

最終MVPで管理する主要データは以下とする。詳細な項目、型、制約、関連はDB設計で定義する。

| データ | 主な内容 |
| --- | --- |
| ユーザー | 認証情報、表示名、AI利用同意 |
| 学習プロジェクト | 名称、概要、期間、状態、アーカイブ情報、作成日時、更新日時 |
| プロジェクト期間履歴 | 変更前後の開始日、変更前後の目標終了日、変更日時 |
| WBSタスク | 種別、親タスク、予定日、予定工数、進捗率、表示順 |
| WBS計画履歴 | 予定日、予定工数、親タスク、変更日時 |
| WBS進捗履歴 | 進捗率、変更日時、対象タスク |
| 学習記録 | 学習日、対象タスク、学習時間、任意メモ、記録時に入力した進捗率 |
| 質問 | 質問内容、カテゴリ、状態、関連プロジェクト・タスク |
| 回答メモ | ユーザーが入力した回答内容 |
| AI回答 | AIが生成した回答内容、生成日時、生成結果 |
| AI送信情報 | AI回答生成時にユーザーが選択した関連情報 |
| AI学習計画入力 | 教材名、OCR結果、貼り付け目次テキスト、自然文の依頼内容 |
| AI学習計画案 | AIが生成したWBS候補、予定日、予定工数、生成結果 |
| AI計画修正案 | AIが生成したWBS、予定日、予定工数の変更差分 |

### 15.1 データ保持方針

- 作成日時、更新日時を主要データに保持する。
- ユーザー所有データには所有者を特定できる情報を保持する。
- プロジェクトはアーカイブによる非表示を基本とし、物理削除しない。
- タスクは関連質問と学習記録が存在しない場合だけ物理削除できる。親タスク削除時は、削除前確認後に配下タスクも削除対象とする。
- 学習記録が存在するタスクも同一プロジェクト内での編集は可能とし、別プロジェクトへ移動できない。
- 質問は確認後、回答メモとAI回答履歴を含めて物理削除できる。
- 学習記録の追加、変更、削除後は、実績工数の集計結果との整合性を保つ。
- 学習記録は、タスク、プロジェクト、ユーザー単位の集計に利用できるように、対象タスク、所属プロジェクト、所有ユーザーを特定できる情報を保持する。
- 過去時点のBAC、PV、EV、バーンダウンを再現するため、計画履歴と進捗履歴を保持する。
- 過去時点のAC、CV、CPIは現在登録されている学習記録に基づいて再計算する。
- 外部サービス固有の情報を主要業務データへ直接埋め込みすぎない。

## 16. 画面要件一覧

詳細なレイアウト、遷移、入力項目は画面設計で定義する。

画面モックはMVP 1だけに閉じず、最終MVP全体の機能配置を見据えて作成する。特にプロジェクト詳細画面は、WBS、学習記録、進捗分析、質問、AI支援が密接に関わる中心画面として扱う。

ただし、各MVPで実装する画面機能は段階リリースに従って切り分ける。MVP 1では、個人用の学習計画・実績管理表として必要なプロジェクト、WBS、学習記録、プロジェクト一覧ホーム、認証を実装対象とし、EVM、バーンダウン、質問、AI支援は画面構造上の配置を考慮するが実装対象外とする。

ナビゲーションは、プロジェクト未選択時とプロジェクト選択後で表示対象を切り替える。プロジェクト未選択時はプロジェクト一覧、プロジェクト作成などの共通機能を中心に表示し、プロジェクト選択後は選択中プロジェクトの概要、WBS、進捗分析、学習記録、質問、AI学習計画生成などのプロジェクト内機能を中心に表示する。
具体的なサイドバー、タブ、パンくず、戻る導線の配置は基本設計で決定する。

| 画面ID | 画面名 | 主な用途 |
| --- | --- | --- |
| SCR-01 | アカウント登録画面 | 新規ユーザー登録 |
| SCR-02 | ログイン画面 | ログイン |
| SCR-04 | プロジェクト一覧画面 | ログイン後のホーム、プロジェクト検索・一覧表示、アーカイブ表示、ユーザー単位の学習サマリー確認 |
| SCR-05 | プロジェクト作成・編集画面 | プロジェクト情報の入力 |
| SCR-06 | プロジェクト詳細画面 | 選択中プロジェクトの概要、主要指標、警告、未完了タスク、プロジェクト内機能への導線の確認 |
| SCR-06A | プロジェクト内進捗分析 | EVM、バーンダウン、計画との差の確認 |
| SCR-06B | プロジェクト内学習記録 | プロジェクト内の学習記録一覧、登録、編集、削除 |
| SCR-07 | WBS編集領域 | 親タスク・タスクの作成・編集・自動並び替え・親タスク設定 |
| SCR-08 | プロジェクト内質問一覧 | 質問の検索・一覧表示 |
| SCR-09 | プロジェクト内質問登録・編集 | 質問、AI回答、回答メモの入力・確認 |
| SCR-10 | AI送信情報選択画面 | AIへ送信する学習記録・回答メモの選択 |
| SCR-11 | AI計画作成: 教材入力画面 | チャット型入力欄での目次テキスト入力、写真・画像ファイル添付、実行・停止 |
| SCR-12 | AI計画作成: 計画チャット画面 | 生成済み計画への自然文追加依頼、修正案、変更差分の確認 |
| SCR-13 | AI計画作成: 生成結果確認画面 | AIが作成したWBSと学習計画の確認・保存 |

### 16.2 プロジェクト詳細画面

プロジェクト詳細画面は、ユーザーが学習プロジェクトの状況を日常的に確認し、次の行動を判断する中心画面とする。
プロジェクト詳細では、WBS、学習記録、進捗分析、質問、AI学習計画生成をプロジェクト内機能として切り替えられる。

| ID | 要件 |
| --- | --- |
| SCR-06-01 | ユーザーはプロジェクト名、概要、状態、開始日、目標終了日、アーカイブ状態を確認できる。 |
| SCR-06-02 | ユーザーはプロジェクトの予定工数、実績工数、残予定工数、進捗率を画面上部で確認できる。 |
| SCR-06-03 | ユーザーは進捗遅延、工数超過、未解決質問の有無を確認できる。 |
| SCR-06-04 | ユーザーはプロジェクト編集、状態変更、アーカイブ、復元、WBS、学習記録、進捗分析、質問、AI学習計画生成へ移動できる。 |
| SCR-06-05 | アーカイブ済みプロジェクトの場合、画面は閲覧専用とし、編集系操作の代わりに復元操作を表示する。 |
| SCR-06-06 | ユーザーは基準日に基づく進捗、遅延を確認し、進捗分析画面へ移動できる。 |
| SCR-06-07 | 基準日の初期値はJSTの当日とする。 |
| SCR-06-08 | ユーザーはプロジェクト詳細からWBS編集領域へ移動できる。 |
| SCR-06-09 | WBS全体の閲覧・編集とガントチャート確認はWBS編集領域で行い、プロジェクト詳細にはWBS全体を表示しない。 |
| SCR-06-10 | ユーザーはプロジェクト詳細内で、未完了タスクのタスク名、終了予定日、進捗率を確認できる。 |
| SCR-06-11 | 未完了タスク一覧では、遅延タスクを上部に強調表示し、その他の未完了タスクを終了予定日の近い順で表示する。 |
| SCR-06-12 | ユーザーはプロジェクト詳細からWBS、学習記録、進捗分析、質問へ移動できる。 |
| SCR-06-13 | ユーザーはプロジェクト詳細で、進捗遅延、工数超過、未解決質問の警告を確認できる。 |
| SCR-06-14 | ユーザーは進捗分析画面で、BAC、PV、EV、AC、SV、CV、SPI、CPIを確認できる。 |
| SCR-06-15 | EVM指標が算出不可の場合、対象指標を「算出不可」と表示し、工数超過や進捗遅延とは区別する。 |
| SCR-06-16 | ユーザーは進捗分析画面で、EVM指標の推移をグラフで確認できる。 |
| SCR-06-17 | ユーザーは進捗分析画面で、理想線と実績線を含むバーンダウンチャートを確認できる。 |

### 16.3 プロジェクト内学習記録

プロジェクト内学習記録は、アプリ外で実施した学習実績をユーザーが手動で登録・確認・編集・削除するプロジェクト詳細内の機能とする。登録された学習記録は、実績工数、連続学習日数、総学習時間、AC、CV、CPIの算出元とする。
プロジェクト横断の学習記録一覧はMVP対象外とする。

| ID | 要件 |
| --- | --- |
| SCR-06B-01 | ユーザーはプロジェクト内の学習記録について、学習日、対象タスク、学習時間、メモの有無を確認できる。 |
| SCR-06B-02 | ユーザーはプロジェクト内の学習記録を学習日降順で確認できる。 |
| SCR-06B-03 | ユーザーは学習日、対象タスク、学習時間を入力して学習記録を登録できる。 |
| SCR-06B-04 | ユーザーは学習記録に任意メモを入力できる。 |
| SCR-06B-05 | ユーザーは学習記録登録時に、任意で対象タスクの進捗率を更新できる。 |
| SCR-06B-06 | ユーザーが進捗率を入力しない場合、対象タスクの進捗率は変更しない。 |
| SCR-06B-07 | 未来日の学習記録を保存しようとした場合、保存せず理由を表示する。 |
| SCR-06B-08 | ユーザーはプロジェクト内の学習記録から登録済み学習記録を編集・削除できる。 |
| SCR-06B-09 | WBSのタスク詳細サイドパネルから学習記録登録へ進む場合、表示中のプロジェクトと選択中タスクを初期選択する。 |
| SCR-06B-10 | 過去日の学習記録をどこまで編集可能にするかは基本設計で決定する。 |

## 17. 外部インターフェース要件

### 17.1 最終MVP

- バックエンドはPC Webから利用するREST APIを提供する。
- REST APIは、将来のFlutterスマホアプリからも利用できるように入出力仕様を整理する。
- APIの入出力はJSONを基本とする。
- AI APIを利用して、登録した質問に対する回答を生成する。
- AI APIを利用して、教材目次画像のOCR、WBS候補、学習計画案を生成する。
- AI APIの認証情報はサーバー側で管理し、PC Webへ公開しない。
- AI APIへ送信する情報は、質問情報、関連タスク情報、ユーザーが選択した学習記録と回答メモに限定する。
- AI学習計画生成時にAI APIへ送信する情報は、ユーザーが修正したOCR結果または貼り付け目次テキスト、教材名、自然文の依頼内容に限定する。
