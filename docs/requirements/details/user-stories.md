## 記載方針

ユーザー目線の目的、価値、受入条件を記載する。

機能要件IDや画面IDとの対応が分かる場合は、関連要件に追記する。

## US-001 23歳 新社会人 男性 研修中にJavaの資格を勉強

### ストーリー

私は、23歳, 新人社員。文系だったが大手SIerに就職し、1からITについて勉強する。
最初は、Java Bronzeという資格試験を取得するつもりだ。
資格試験対策本を買ったものの、どれくらい勉強すれば本一冊の勉強が完了するのかが分からないので、学習計画を立てたい。
どうせなら、エンジニアらしく計画はWBSを作成して管理することで、ただ勉強するだけでなく計画管理
するスキルを身に付けたい。
ただ、計画を立てるのは面倒だし、計画と実績がずれてきた時に、計画表を修正するのが面倒になって、勉強も辞めてしまうことが多いんだよな、、

## US-002 25歳 社会人3年目 女性 ウォーターフォール全工程は経験したが、体系的にアーキテクチャについて学びたい

### ストーリー

私は、25歳, システムエンジニア。1,2年目は激務だったが、要件定義からテスト工程まですべて経験できた。
テスト工程で案件が炎上し、忙しい日々だった。その時に感じたのは、アーキテクチャが良くなかったということ。
だからこそ、良い設計とはどのような設計なのかを、改めて体系的に学びたい。
アーキテクチャ入門のような本を買ったが、すべてのページを読むのもなんか非効率だし、必要そうなページをさらっと
読むだけにしたい。そんな計画を立てたいが、難しいな。次の案件は小さい案件のリーダーだから管理手法についても
勉強したいし。忙しい〜。

## US-004 28歳 社会人6年目 男性 資格取得と実務の両立

### ストーリー

私は、28歳のバックエンドエンジニアです。
普段は開発案件に入っていて、平日はまとまった勉強時間を取りにくい。
それでも、クラウド系の資格を取りたいので、限られた時間の中で何を優先して勉強すべきかを整理したい。
参考書、公式ドキュメント、問題集を行き来していると、どこまで進んだのか分からなくなる。
学習範囲をWBSに分けて、予定と実績を見ながら、遅れている部分を早めに把握したい。
予定より遅れているときは、AIに計画の組み直し案を出してもらえると助かる。

## US-005 31歳 チームリーダー 女性 後輩の学習支援をしたい

### ストーリー

私は、31歳のチームリーダーです。
新人や若手メンバーにJavaやSQLを勉強してもらいたいが、何をどの順番で学べばよいかを毎回説明するのは大変だ。
本人が教材の目次から学習計画を作り、日々の進捗や疑問点を自分で管理できるようになってほしい。
質問が出たときに、まずAI回答を参考にして自分なりの回答メモを残せると、理解度も確認しやすい。
将来的には、本人が作ったWBSや学習記録を見ながら、1on1でどこにつまずいているかを話せるようにしたい。
