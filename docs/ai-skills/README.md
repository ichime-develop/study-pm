# AI Skill

## 目的

このフォルダは、AIに作業させるための開発支援ルールを管理する。

ここに置くファイルは、アプリの正式成果物ではない。

## 成果物との違い

- `docs/requirements/` や `docs/design/` は、人間が確認する成果物を置く。
- `docs/ai-skills/` は、AIに作業させるための入力ルール、出力形式、注意点を置く。
- レビュー結果は対象成果物の `review/` 配下に置く。
- レビュー方法は `docs/ai-skills/` に置く。
